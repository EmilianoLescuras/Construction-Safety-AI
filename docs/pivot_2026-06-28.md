# Pivot — 2026-06-28: 19-class construction → 34-class riskalert-mining

## What changed

The project's dataset was switched from the original 19-class construction
PPE set (`config/data.yaml`, English) to the **34-class riskalert-mining**
set (`config/data_riskalert.yaml`, Spanish), exported from Roboflow
(`emilianos-workspace-6gmup/riskalert-mining-r07if` v1).

## Why

Decision taken explicitly on 2026-06-28 to retarget the detector at the
richer mining + PPE + road-state taxonomy. The new set covers PPE
compliance per-person (`PERSONA_CON_CASCO`, `PERSONA_SIN_CHALECO`, …),
mining vehicles (`VOLQUETE`, `MOTONIVELADORA`, `EXCAVADORA`, …) and road
condition (`VIA_*`).

## Impact

- **Taxonomy:** 19 → 34 classes; labels are in Spanish.
- **Models obsolete:** the construction v1/v2 weights
  (`yolov8n_construction_safety_e40_cache.pt`, `yolov8s_construction_safety_e60.pt`)
  were trained on the old 19-class schema and do **not** transfer — the new
  model trains from `yolov8s.pt` base weights.
- **Data location:** `~/Downloads/riskalert-mining-pivot.yolov8/`
  (712 imgs: 498 train / 142 valid / 72 test; gitignored, outside the repo).
- **Class balance:** heavy imbalance, 15 sparse classes (<20 instances) —
  see `docs/dataset_stats_riskalert.md`.

## Next

evaluate on val + test and record in
`docs/experiments/yolov8s_riskalert_e60.md`.
